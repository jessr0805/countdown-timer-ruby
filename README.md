# Countdown Timer (RUBY)
A Ruby-based Countdown Timer for people who want to have fun, test their knowledge, or check out what basic Ruby code looks like.
## Cool Features
- **Custom Timer Duration**
- **Live Terminal Progress Bar**
- **Real-Time Percentage Tracking**
- **Input Validation**
## How to Run It
Ensure Ruby is installed
If it isn't visit the 
[Official Ruby Installer Link](https://www.ruby-lang.org/en/downloads/)
To run the quiz directly in the terminal,
- Clone the repository
- Navigate to the repository in your terminal
- Run
  ```bash
  ruby timer.rb
  ```
